═══════════════════════════════════════════════════════════════════════════
                            DATA FLOW EXAMPLES
═══════════════════════════════════════════════════════════════════════════

1. USER LOGIN FLOW:
   User enters credentials → Frontend /login
       ↓
   POST /api/login {userId, password}
       ↓
   Backend validates against MongoDB users collection
       ↓
   Generate & return JWT token + user data
       ↓
   Frontend stores token & redirects to Dashboard
       ↓
   All future requests include: Authorization: Bearer {token}


2. SALES DATA UPLOAD FLOW:
   Admin uploads Excel/CSV → Frontend upload form
       ↓
   POST /api/sales-records (multipart/form-data)
       ↓
   Backend parses file (xlsx/csv-parser)
       ↓
   Validate & normalize headers (case-insensitive)
       ↓
   Transform to MongoDB schema
       ↓
   Bulk upsert to sales_records collection
       ↓
   Return success/error response
       ↓
   Frontend shows confirmation & refreshes data


3. REAL-TIME KRA SYNC FLOW:
   External system updates Firebase → /logs_HYD/daily_logs
       ↓
   Firebase triggers 'value' event
       ↓
   Sync Service listener detects change
       ↓
   Fetch all records from Firebase path
       ↓
   Normalize names to Title Case
       ↓
   Prepare bulk upsert operations
       ↓
   Execute bulkWrite to MongoDB KRA_Reports_HYD
       ↓
   Log sync statistics (new: X, updated: Y)


4. DASHBOARD DATA RETRIEVAL:
   User views Dashboard → Frontend requests data
       ↓
   GET /api/sales-records?branch=HYD&month=FEBRUARY
       ↓
   Backend queries MongoDB with filters
       ↓
   Aggregate data (totals, averages, rankings)
       ↓
   Return JSON response
       ↓
   Frontend renders: Charts, KPIs, Tables, Rankings

═══════════════════════════════════════════════════════════════════════════
                         SECURITY LAYERS
═══════════════════════════════════════════════════════════════════════════

Layer 1: TRANSPORT
   • HTTPS/TLS encryption
   • Secure WebSocket connections

Layer 2: AUTHENTICATION
   • JWT tokens (12-hour expiry)
   • Secure password storage (AES encryption)
   • bcrypt fallback for legacy passwords

Layer 3: AUTHORIZATION
   • Role-based access control (RBAC)
   • Middleware: authenticateToken, requireAdmin
   • Route-level permissions

Layer 4: DATA PROTECTION
   • MongoDB encrypted connections
   • Environment variable protection
   • Input validation & sanitization
   • CORS whitelisting

Layer 5: APPLICATION
   • Error boundary handling
   • Rate limiting (future)
   • Audit logging (admin actions)
